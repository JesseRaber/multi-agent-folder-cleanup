# Multi-Agent Folder Cleanup v2.0.0

## What changes

- New Setup mode applies bundled project rules to a named folder, preserves existing records and verifies adoption.
- Host-aware setup provides instruction blocks for the actual runtime and access route, with safe fallbacks for browser and upload-only agents.
- One explicit approval can cover a defined workflow. Required checks, scope boundaries and mandatory host confirmations remain in force.
- Closeout preserves substantive decisions, corrections, evidence limits and unresolved work. Continued sessions append history instead of rewriting earlier close entries.
- Published packages gain clear local navigation and verification records; drafts and candidates stay distinct.

## Compatibility

This major version introduces a new operating mode and changes the authorization/closeout protocol. Existing helper flags and project record paths remain supported. The bundled Project Rules remain4.0.1; installing the skill does not adopt or replace a project's rules. Hosts that omit the optional rules template must obtain it before applying rules.
