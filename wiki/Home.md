# Multi-Agent Folder Cleanup

Agent skill for a shared project folder used by more than one AI model. It keeps Claude, ChatGPT, Codex, Microsoft Copilot, Gemini, Grok, Opal, and local models from treating a stale copy, an incoming draft, or a second roadmap as current. Work mode covers ordinary saving, naming, indexing, and handoff. Cleanup modes (Audit, Plan, Execute) inventory, propose, and apply verified reorganization without treating documentary claims as verified state.

Current version: **1.8.0** (main branch at or after commit 1d5e495).
